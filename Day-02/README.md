# Day 02 — Operators, expressions, truthiness and comparisons

## Outcomes
Understand and apply operators, expressions, truthiness and comparisons in a small Python codebase.

## Study
- Arithmetic (+ - * / // % **)
- comparisons
- boolean short-circuiting
- membership
- identity
- truthiness and None checks.

## Practical work
1. Calculate average latency
2. decide whether retry is allowed
3. compare equal-but-distinct lists with == and is
4. validate positive non-boolean timeouts
5. explain why identity is not value equality.

## Senior perspective
Be explicit when zero or an empty value is meaningful. Use is primarily for singleton checks such as value is None.
