# Python AI Engineering Mastery

A practical 90-day curriculum for progressing from Python fundamentals to senior-level Python engineering and AI/LLM architecture.

## Setup
Requires Python 3.12+.

```bash
git clone https://github.com/adm-l/python-ai-learning.git
cd python-ai-learning
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

Start with [Day 01](Day-01/README.md). Run `python Day-01/examples/variables.py`.

## How to study
1. Study one day at a time; type examples yourself.
2. Complete exercises independently.
3. Add tests and run from a clean environment.
4. Explain design decisions and failure cases.
5. Keep your practice commits on a personal branch.

## Curriculum
- Days 01–15: Python foundations
- Days 16–30: Professional Python, typing, testing, packaging and design
- Days 31–45: Runtime, async, concurrency, performance and reliability
- Days 46–60: Data engineering, FastAPI, databases, Docker and observability
- Days 61–75: LLM APIs, tokenization, embeddings, vector search and RAG
- Days 76–90: MCP, LangGraph, agent state, safety, evaluation and production architecture

See [ROADMAP.md](ROADMAP.md) for the complete daily syllabus.

## Definition of done
- [ ] Explain the day's concepts without reading notes.
- [ ] Run every example.
- [ ] Complete exercises independently.
- [ ] Add tests for important behavior and edge cases.
- [ ] Record one trade-off, one failure mode and one unresolved question.

Finishing a 90-day syllabus does not automatically make someone a senior architect. Senior ability comes from repeated implementation, debugging, code review, operational ownership and explaining trade-offs.
