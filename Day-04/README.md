# Day 04 — Lists and sequence operations

## Outcomes
Understand and apply lists and sequence operations in a small Python codebase.

## Study
- Indexing
- slicing
- mutation
- append/extend/pop
- sorting
- aliasing
- shallow copies and operation costs.

## Practical work
1. Maintain last 10 latencies
2. deduplicate while preserving order
3. sort records by a key
4. demonstrate aliasing
5. implement positive-size batching.

## Senior perspective
Choose structures based on access patterns. Avoid mutating a list while iterating over it unless deliberate.
