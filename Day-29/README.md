# Day 29 — Code quality and security basics

## Outcomes
Understand and apply code quality and security basics in a small Python codebase.

## Study
- Formatting
- Ruff concepts
- static typing
- dependency audit
- path traversal
- unsafe deserialization and secret scanning.

## Practical work
1. Run formatter/linter/type checker
2. add tests for untrusted paths/payloads
3. review dependencies
4. fix findings.

## Senior perspective
Tools catch defect classes but do not replace threat modeling and code review.

## Acceptance
- [ ] Explain the key concepts without reading the lesson.
- [ ] Implement the practical work.
- [ ] Add tests for success, edge and failure cases.
- [ ] Run from a clean virtual environment.
- [ ] Record one trade-off and one unresolved question.
