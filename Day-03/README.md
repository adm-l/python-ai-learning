# Day 03 — Strings, formatting, Unicode and text processing

## Outcomes
Understand and apply strings, formatting, unicode and text processing in a small Python codebase.

## Study
- String literals
- escaping
- indexing
- slicing
- immutability
- f-strings
- split/join/strip/replace/casefold and Unicode code points.

## Practical work
1. Normalize whitespace
2. parse a sample log line defensively
3. format latency
4. test emoji and accented text
5. explain why Python string length is not an LLM token count.

## Senior perspective
Text processing is central to AI, but Unicode characters and model tokens are different concepts.
