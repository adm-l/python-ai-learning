# Day 12 — Exceptions and defensive input handling

## Outcomes
Understand and apply exceptions and defensive input handling in a small Python codebase.

## Study
- Exception hierarchy
- try/except/else/finally
- raise from
- custom exceptions
- validation vs operational errors.

## Practical work
1. Create domain exceptions
2. parse configuration safely
3. preserve exception cause
4. prove cleanup on failure
5. design safe client error responses.

## Senior perspective
Catch only where you can recover, translate or add context. Do not silently swallow failures.
